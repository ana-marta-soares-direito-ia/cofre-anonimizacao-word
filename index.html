para Microsoft Word

Suplemento que identifica e substitui os dados pessoais de peças processuais, contratos e pareceres directamente no Word, em segundos, sem enviar o documento para qualquer servidor externo. Utilização

  1. Abra o documento e guarde uma cópia com outro nome.
  2. Seleccione Base > Anonimizar e, no painel, Analisar documento.
  3. Reveja a lista: desmarque o que não deve ser substituído, utilize Localizar para confirmar o contexto e acrescente os termos que não tenham sido identificados.
  4. Escolha o modo (pseudonimização, anonimização com etiquetas ou rasura) e seleccione Aplicar ao documento.
  5. Na pseudonimização, abra a tabela de correspondências num novo documento e guarde-a separadamente. Nunca a envie com o documento nem a cole num sistema de inteligência artificial.
  6. Para repor os dados num documento trabalhado, abra o separador Repor dados, indique a tabela e seleccione Repor dados no documento.

A detecção assenta em regras e em léxicos de nomes e exige revisão humana. O texto contido em imagens, caixas de texto e objectos incorporados não é tratado. Os dados pseudonimizados continuam a ser dados pessoais na acepção do artigo 4.º, n.º 5, do RGPD.

Perguntas frequentes

Como anonimizar um documento Word com dados pessoais?

Com o Cofre de Anonimização aberto no Word, selecciona-se Analisar documento: o suplemento identifica nomes, NIF, NISS, cartão de cidadão, IBAN, moradas, contactos e números de processo, apresenta a lista para revisão e substitui os dados escolhidos por etiquetas ou por rasura, mantendo a formatação do documento.

Qual é a diferença entre anonimização e pseudonimização no RGPD?

Na pseudonimização, os dados são substituídos por etiquetas e conserva-se, em separado, a tabela que permite repô-los; os dados pseudonimizados continuam a ser dados pessoais (artigo 4.º, n.º 5, do RGPD). Na anonimização, a substituição é irreversível e não fica qualquer tabela de correspondências, pelo que o documento deixa de permitir a identificação dos titulares (considerando 26 do RGPD).

Posso usar documentos de clientes em ferramentas de inteligência artificial?

O dever de segredo profissional e o RGPD impõem que os documentos não sejam enviados com dados identificativos para serviços externos. O Cofre permite anonimizar ou pseudonimizar o documento no próprio computador antes de o utilizar com uma ferramenta de inteligência artificial e, no caso da pseudonimização, repor depois os dados no texto trabalhado.

O documento é enviado para algum servidor?

Não. A análise e a substituição decorrem no computador do utilizador. O texto não é transmitido, registado nem conservado.

Funciona no Mac e no Windows?

Sim. O suplemento funciona no Word para Windows, no Word para Mac e no Word na Web, com o Microsoft 365, o Office 2021 ou uma versão posterior. A instalação demora cerca de um minuto.
