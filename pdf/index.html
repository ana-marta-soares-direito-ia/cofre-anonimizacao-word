Cofre PDF

Anonimização local de documentos PDF

Abra um PDF

Arraste o ficheiro para aqui ou seleccione Abrir PDF. O documento é tratado neste computador e não é enviado para qualquer servidor.

Abrir os PDF directamente no Cofre

  1. Nesta página, no Google Chrome, no Microsoft Edge ou no Brave, seleccione Instalar no computador (ou o ícone de instalação na barra de endereço).
  2. No Mac, clique com o botão direito num PDF e seleccione Abrir com > Cofre PDF. No Windows, clique com o botão direito e seleccione Abrir com > Cofre PDF.
  3. Na primeira vez, autorize o Cofre a abrir o ficheiro. A partir daí, o PDF abre já pronto a anonimizar.

Elementos identificados

Abra um PDF para começar.

Para rasurar uma assinatura, um carimbo ou uma imagem, arraste o rato sobre a zona no documento. Para retirar uma caixa manual, clique nela.

Resultado

No PDF anonimizado, os dados originais deixam de existir no ficheiro: cada página é reconstruída e o texto pesquisável contém apenas XXXXX ou as etiquetas no lugar dos dados, pelo que não podem ser recuperados por cópia, pesquisa ou ferramentas de inteligência artificial. O texto pseudonimizado destina-se a ser trabalhado em sistemas de inteligência artificial; a tabela permite repor os dados com o Cofre para Word.
